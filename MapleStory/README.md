# MapleStory Artale 自動按鍵工具

給楓之谷 Artale 用的自動按鍵控制小工具（Windows Forms / .NET 8）。透過 `SendInput` 模擬硬體層級的按鍵事件，依照選定的行為模式（Set）自動觸發技能與移動。

## 需求

- Windows
- .NET 8 SDK（`net8.0-windows`）

## 建置與執行

```bash
dotnet build MapleStory.sln
```

```bash
dotnet run --project MapleStory
```

或直接用 Visual Studio 開啟 `MapleStory.sln`。

建置結果在 `MapleStory\bin\Debug\`（已關閉 `AppendTargetFrameworkToOutputPath`，所以沒有 `net8.0-windows` 那層子目錄）。日常使用建議改用 Release 建置，執行效率較好：

```bash
dotnet build MapleStory.sln -c Release
```

## 使用方式

1. 開啟程式後，先在下拉選單選擇要執行的行為模式（`Set 1` / `Set 2` / `Set 3`）。
2. 確認「遊戲視窗標題關鍵字」欄位符合你的遊戲視窗標題（預設 `MapleStory`）。工具只會在標題含此關鍵字的視窗位於前景時送出按鍵。
3. 切到楓之谷遊戲視窗。
4. **Set 1 / Set 2**：回到工具視窗按 **Start**，會先等待 3 秒讓你切回遊戲畫面，之後開始依所選 Set 的邏輯循環送出按鍵。
5. **Set 3**：按全域快捷鍵 **F5**（或工具上的「施放技能」鈕）觸發單次施放，不需要按 Start。
6. 停止方式（Set 1 / Set 2）：
   - 按工具視窗上的 **Stop**，或
   - 在任何視窗按全域快捷鍵 **F11**（透過 `RegisterHotKey` 註冊，不需要工具視窗在前景）。

執行中下拉選單會被鎖定，停止後才能再切換模式。狀態列與視窗標題會同步顯示目前狀態（待機中／準備中／執行中／已暫停／停止中）。

### 遊戲視窗焦點偵測

所有按鍵都只在遊戲視窗位於前景時才會送出。若中途切到瀏覽器等其他視窗，程式會**原地暫停等待**（而不是跳過該按鍵），等你切回遊戲後從中斷處接續，因此 Set 2 這類固定順序排程不會被打亂。

## 行為模式

### Set 1

計時觸發技能鍵（F）＋高頻率連續攻擊鍵（A），時間間隔皆帶隨機抖動。

### Set 2

固定順序排程（F → 空白鍵 → D → C → X，並穿插左右移動），同樣帶隨機抖動避免固定節奏。

### Set 3（單次施放 + 冷卻倒數）

手動觸發的技能組合，依序施放 **A → F → X → C**（鍵與鍵之間隨機間隔 1～3 秒），跑完一輪即結束，不會持續循環。

搭配冷卻倒數提醒：

- 按下 **F5 的當下**起算 **4:00** 倒數（不是等技能序列跑完才起算），重新按下即刷新。
- 倒數歸零後進入最多 **20 秒**警示，每秒發出一次提示音，倒數文字轉紅。
- 警示期間若沒有手動重新施放，會**自動補放一次**同樣的技能序列並重新倒數；此後倒數文字維持紅色，直到你自己按 F5 才恢復。

#### 倒數浮動視窗

勾選「顯示倒數浮動視窗」會開啟一個常駐畫面最上層的小視窗顯示倒數。它刻意設定為：

- **點擊穿透**（`WS_EX_TRANSPARENT`）：滑鼠點擊直接傳給下面的遊戲，不會擋到操作。
- **不搶焦點**（`WS_EX_NOACTIVATE`）：否則它一取得焦點就會讓「遊戲視窗使用中」判斷失效而停止送鍵。
- **不出現在 Alt-Tab／工作列**（`WS_EX_TOOLWINDOW`）。

因為點擊穿透就無法拖曳，要調整位置請按「解鎖位置（可拖曳）」暫時關閉穿透，拖好後再按「鎖定位置」恢復。

### 新增其他模式

在 `Form1.cs` 新增對應的 `RunTemplateXAsync` 方法、在 `btnStart_Click` 加一個 `else if (currentTemplate == X)` 分支，並在 `Form1_Load` 的 `cmbTemplate.Items.AddRange(...)` 裡加上選項文字即可。

## MP 監控自動補水（開發中）

> **狀態：功能調整中，尚未定案。** 量測準確度仍在調校，請先自行確認讀值正確再依賴它。

勾選「啟用 MP 監控」後會在背景持續量測畫面上的 MP 血條填滿比例，低於設定的百分比就自動按下指定的補 MP 按鍵（附 2 秒冷卻，避免連續狂按）。此開關獨立運作，不受目前選到哪個 Set 或有沒有按 Start 影響。

### 校準步驟

1. **先把 MP 補到全滿**（重要——校準時偵測到的藍色範圍會被當作 100% 的基準）。
2. 按「校準 MP 範圍」，工具會縮到最小，接著用滑鼠框選 MP 藍色橫條。
3. 大概框到即可，程式會自動找出血條範圍；多框到數字、邊框、背景都會自動忽略。
4. 校準完成後狀態列會顯示偵測到的血條尺寸；失敗則會顯示原因。

量測原理：以**色相**辨識血條填滿色（而非整個 RGB 距離），因此血條上的分隔線與亮度漸層不影響判讀；再逐行統計填滿像素密度，取最右側的填滿行位置換算百分比。

## 已知限制 / 疑難排解

- 按鍵是用 `SendInput` 送到目前的前景視窗，若遊戲視窗沒有焦點（被其他視窗蓋掉、彈出通知等），按鍵就送不到遊戲裡。
- 若楓之谷用系統管理員身分執行，而本工具不是，Windows 的 UIPI（User Interface Privilege Isolation）會直接擋掉輸入且不會有例外或錯誤視窗——這種情況請將本工具也以系統管理員身分執行。
- 方向鍵等延伸鍵已加上 `KEYEVENTF_EXTENDEDKEY` 旗標，避免被系統誤判為數字鍵盤輸入。
- 工具視窗自己的標題也含有 `MapleStory`，程式已排除自身與浮動視窗的 handle，避免誤判成遊戲視窗。若你把「視窗標題關鍵字」改成別的字串，請確認不會同時命中其他無關視窗。
- MP 監控與畫面校準都依賴螢幕擷取，遊戲若以獨占全螢幕模式執行可能擷取不到畫面，建議使用視窗化或無邊框視窗模式。
